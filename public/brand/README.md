# 大福映画 Felina Gallery · Logo

卡通版 logo。**配色不是随手选的**，每一处都有出处：

| 用途 | 颜色 | 来源 |
|---|---|---|
| 猫毛 | `#F0DCC0` / `#D8B48C` | 四张生产照片**中心区域**实测主色 `#E0C0A0` / `#C0A080` / `#A08060` |
| 描边 | `#4C3C33` | `animal-island-ui` 图标统一的深棕描边 |
| 项圈 | `#19C8B9` | ACNH `--animal-primary-color`（与 App 青色分区标题一致） |
| 铃铛 | `#FFCF4F` | ACNH `icon-design` 的黄色 |
| 耳朵/鼻子 | `#E68E6D` | ACNH `icon-diy` 的陶土色 |
| 卡片 | `#F7F3DF` / `#C4B89E` | ACNH 纸卡色与描边 |

## 题材依据
照片**标题**（文字信息）指向猫：偶遇小猫 / 端庄公主 / 美照（佩戴Airtag版）/
阳光下的酣睡 / 注视 / 打个哈欠吧。站点作者写的是 **Felina**（feline），
站名 **大福** 是猫名。所以画的是"一只猫"。

## 文件
- `felina-logo-icon.svg` / `.png` — 1024×1024 方形图标（圆角卡片外透明）
- `felina-logo-banner.svg` / `.png` — 2048×768 横幅（图标 + 中英文名）

## 已知限制
1. **猫的实际毛色/花纹无法从像素可靠推断** —— 用的是"中心区域主色"这个统计量。
   如果大福不是奶油色，改上表的"猫毛"两个色值即可。
2. 横幅里的文字用的是系统字体（PingFang SC / Nunito）。作为网页素材没问题；
   若要用在印刷或需要字形完全一致的场合，需要把文字转成路径。
