# PicImpact 性能优化实施计划（P0 + P1 批次）

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:executing-plans 逐任务实施本计划。步骤用 `- [ ]` 跟踪。
>
> **Spec:** [`docs/superpowers/specs/2026-10-03-performance-design.md`](../specs/2026-10-03-performance-design.md) —— 本计划从该设计的 §6 P0/P1 派生，执行者需同时阅读 spec 的 §1（实测基线）与 §4（根因）。

**Goal:** 在不动视觉设计与业务功能的前提下，把首屏图片从 118.5 MB 降到 < 2 MB、每页 CSS 从 483 KB 降到 < 80 KB、中文字体从 3.39 MB 降到 < 150 KB，并消除每次导航 700–1000ms 的人为阻塞。

**Architecture:** 三条互不耦合的改动线：① 网格只渲染缩略图并直连资产域（摘除不可缓存的代理路径）；② 删除未被引用的库 CSS 与未分片的字体，改用已验证存在的 unicode-range 分片；③ 移除全屏 GSAP 过场与其最小显示时长。

**Tech Stack:** Next.js 16.1.6（Turbopack）、React 19.2.4、Tailwind v4、`animal-island-ui@1.0.16`、`@fontsource/noto-sans-sc@5.2.9`、`sharp@0.34.5`、pnpm。

## Global Constraints

- 不改视觉设计语言（配色、圆角、卡片样式、字体字形字重）。
- 不改业务语义（相册/标签/EXIF/地图/后台能力全部保留）。
- 不升级大版本依赖。
- 每项改动必须能独立回滚（单个 commit 粒度）。
- 本批次**不含**缩略图生成与数据迁移（那是 P0.1–P0.3，独立后续批次）。
- 验证命令统一为：`pnpm build`（或在 pnpm 严格安装下 `npx next build`），并对生产做 `curl -sS -o /dev/null -D -` 的 **GET**（非 HEAD）实测。
- **测量纪律**：Cloudflare 不缓存 HEAD 请求，一切缓存结论必须用 GET 得出。

## Review Focus

- **资产域直连后的防盗链/CORS 回归**：直连依赖 `access-control-allow-origin: *`（已实测存在）。若某天该头被移除，图片会全部加载失败——这是本批次最大的单点风险，必须在验收时复核。
- **字体剥离 PostCSS 步骤的错误匹配**：正则若过宽会误删 `animal-island-ui` 的组件样式（61.3 KB），表现为按钮/弹窗/图标样式崩坏。
- **去除 GSAP 过场后的首次导航**：`progress-bar-providers` 目前猴补丁了 `window.history.pushState`，移除后需确认 `next-nprogress-bar` 的进度条仍正常工作。
- **网格移除 HD 图层后的"HD"徽标语义**：徽标原本表示"原图已就绪"。若保留徽标但不再预取原图，徽标将永不出现——需按 spec 决定是删除徽标还是改为点击进预览。
- **HeroUI CSS 删除后的样式回归**：`@heroui/styles` 会引入 Tailwind 的 `@layer` 声明与 `@theme` 变量，删除后需确认 Tailwind 的 layer 顺序未变（表现为 `@layer` 相关工具类失效）。

## Task 2: 图片直连资产域，摘除不可缓存的代理路径

**依据**：spec R1/P0.7 + §1.1.1（修正后结论）。实测 `/api/public/url-proxy` 恒为 `DYNAMIC`（无扩展名），而直连资产域为 `HIT`；且资产域已确认 `access-control-allow-origin: *`、无防盗链。

Expected: 56（56 次代理引用）

- [ ] **Step 2: 让 toProxyImageUrl 默认直连**

把 `lib/utils/image-proxy.ts` 的 `toProxyImageUrl` 改为直连，并把代理能力保留为显式开关：

```ts
// 缩略图/预览图默认直连资产域：资产域已开启 CF 边缘缓存（HIT）且允许跨域（ACAO: *），
// 而 /api/public/url-proxy 无扩展名、不可被边缘缓存，会成为每张图的额外源站往返。
// 仅在需要代理兜底时（如资产域策略变更）把 ENABLE_IMAGE_PROXY 置为 true。
const ENABLE_IMAGE_PROXY = false
const PROXY_ROUTE_PREFIX = '/api/public/url-proxy?url='

export function toProxyImageUrl(rawUrl: string | null | undefined): string {
  if (!rawUrl) return ''
  if (!ENABLE_IMAGE_PROXY) return rawUrl
  if (rawUrl.startsWith(PROXY_ROUTE_PREFIX)) return rawUrl
  return `${PROXY_ROUTE_PREFIX}${encodeURIComponent(rawUrl)}`
}

export function isProxyImageUrl(url: string | null | undefined): boolean {
  return Boolean(url?.startsWith(PROXY_ROUTE_PREFIX))
}
```

- Produces: 字体族名仍为 `Noto Sans SC` 与 `Nunito`，字重不变 → 消费方（`style/globals.css:160`、`animal-island-ui` 的 `--animal-font-family`）无需改动

- [ ] **Step 1: 记录改动前的字体产物**

- [ ] **Step 2: 加 PostCSS 步骤剥离 animal-island-ui 的未分片 @font-face**

```js
const stripBundledFontFaces = () => ({
  postcssPlugin: 'strip-bundled-font-faces',
  Once(root) {
    root.walkAtRules('font-face', (rule) => {
      if (/files\/(noto-sans-sc|nunito)-/.test(rule.toString())) rule.remove()
    })
  },
})
stripBundledFontFaces.postcss = true
```

并把 `plugins` 数组里加入 `stripBundledFontFaces()`。
